## Implementation Notes

- The existing Jenkinsfile uses `docker compose -f docker-compose.yml build` and deploys the repo to `DEPLOY_PATH`.
- Keep the smoke checks shell-only so they can run locally or from Jenkins.
- Do not require an authenticated browser E2E test in this phase; document a manual authenticated task-board check.
